# SltBox 2026110501

本次更新相对于正式版 **2026103002**，主要新增可选的 2.5D 种树地图，完善镜头观察、透明背景和物件挂载，并增加水果出售价格记录、修复天空飞鸟点击问题。

## 新增：2.5D 种树实验效果

- 在“设置 → 功能格子 → 种树”增加“3D 实验效果”开关。默认关闭，升级后继续显示原有 2D 树木；主动开启后立即切换到地图效果，关闭即可恢复 2D。
- 五个成长阶段分别使用低多边形树干、树枝和树冠组合，保留果实、动物、已部署装饰、天气和树冠摆动等展示。
- 树木置于可观察的地图中，周围增加草地、小径、池塘、林木、石块、长椅和围栏。地图只影响视觉，不增加采集、交易或地图探索奖励。
- 按住鼠标左键拖动可旋转视角并调整俯角；方向键沿当前观察方向移动；鼠标滚轮向上放大、向下缩小，范围为默认距离的 0.55～2.8 倍；Home 回到树木初始视角并恢复默认缩放。
- 点击果实与动物继续调用原有采摘和捕捉流程。鼠标拖动达到旋转阈值后不触发采摘或捕捉，避免观察地图时误操作。
- 实验开关单独保存在本机。切换账号不改变本机视觉偏好，也不会将该偏好作为树木进度上传。

## 调整与修复：地图显示和镜头

- 地图随格子实际高度自动伸缩，能量、捕捉提示和阶段进度按实际内容保留底部空间；宽、窄、高、矮布局均通过相机比例适配，避免固定高度造成空白。
- 连续调整格子尺寸时保留当前旋转、观察位置和滚轮缩放，不重新创建场景。原有 2D 及失败回退仍保持 130 高度。
- 修复树后方出现浅色不透明块、遮住格子自定义背景的问题。地图通过透明画面与原生界面合成，保留自定义背景的显示。
- 修复旋转、移动或俯视后果实和装饰脱离树木、看起来浮在天空的问题：将平面布置坐标绑定到实际树冠或树干表面，边缘位置吸附到最近树体表面；固定挂载位置不随镜头重新计算。
- 树冠装饰与果实跟随树冠轻微摆动，树干装饰固定在树干；地面装饰保持竖直、底部落地，不随镜头俯仰而悬空。
- 果实与装饰增加树体和地图深度遮挡。被树木遮住的果实不会穿透树叶显示，也不能从树背面点穿采摘。
- 移除地图上的“拖动旋转、滚轮缩放”等鼠标悬停提示，相关操作功能继续保留。
- 隐藏窗口时停止地图绘制，恢复显示后重新绘制；关闭系统动画时仍可手动旋转、移动和缩放。
- Three.js、页面和素材全部本地打包，不依赖 CDN。WebView2 初始化、导航、脚本或图形运行失败时自动回退 2D，并提示一次；使用 3D 需要系统可用的 WebView2 Runtime。

## 新增：水果市场最近出售价格

- 每种水果的“7日”市场价格下方，增加当前账号最近 **7 次出售成交单价**，帮助对照历史市场价格与实际卖出价格。
- 记录按最近出售顺序展示，展示的是每次出售的单价，数量和总收入仍按原有交易流程计算。
- 没有出售记录的水果不显示该行。出售成功后刷新水果状态，读取最新记录。
- 出售记录由服务端按账号查询，本地缓存同样按账号隔离；切换账号清理上一账号的记录，避免混用。

## 修复：天空飞鸟点击与捕捉

- 改善从右向左飞行动物的点击区域和移动边界，扩大天空飞行的可用捕捉区域，减少图像可见却难以点中的情况。
- 将天空飞鸟点击统一转到种树场景处理，修复点击后完全没有反应的问题，同时保留原有捕捉校验、奖励与失败反馈。
- 同步调整到访界面中飞行动物的显示和运动区域。

## 数据与兼容

- 不改变种树阶段所需能量、键盘计数、果实奖励、动物库存、装饰库存、好友排行或树木云同步协议。
- 原有 2D 绘制保留；3D 是可关闭的实验展示。2D 中保存的装饰位置和账号数据不被地图转换覆盖。
- 水果出售记录使用配套服务端接口。旧缓存缺少记录时仍能正常加载，不会凭空生成历史成交价格。
- 本次提供 Windows x64 Direct Full Native AOT 安装包 `SltBox_Setup_2026110501_x64.exe`，延续上一版完整载荷方式；不发布 ARM64 或 Microsoft Store 包。
- 支持 Windows 10 21H2（19044）及以上 x64 系统。安装包未签名，提供同名 `.sha256` 文件核对。
- 更新下载优先使用 GitHub，失败时使用 HTTP 镜像，并使用 HTTPS 更新清单中的 SHA-256 校验安装包。
