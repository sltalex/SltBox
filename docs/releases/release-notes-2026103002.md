# SltBox 2026103002

本次更新相对于正式版 **2026102702**。继续完善钉钉群文档、种树、动物图鉴和商城；树木装饰目录恢复为原有 20 件。

## 新增功能

### 钉钉群文档

- 在钉钉格子设置中增加“每页显示”条数。默认每页 5 条，可在 1～50 条之间调整；格子按所选条数分页，切换筛选或搜索时回到第一页。
- 群文档索引、手动添加的文档、收藏内容和同步间隔通过账号关联的服务端接口保存。换电脑登录同一 SltBox 账号并完成钉钉授权后，可以读取已保存的文档索引和相关设置，减少重复扫描。
- 收藏同步加入本地变更基线：新增、取消收藏和远端内容合并后再保存，避免旧收藏在换电脑或同步时被整份覆盖。服务端文档索引按规范化链接合并，减少重复文档。

### 种树与动物

- 种树设置增加“今日键盘敲击次数”，显示在“同步校准”左侧，随计数变化更新，方便核对能量未增长时的输入记录。
- 在“参与排行榜”左侧增加“前端展示能量值”开关，默认关闭。开启后，树木格子在树下方显示能量值；重置树木记录时保留该显示偏好。
- 果实位置改为树冠内稳定的分散布局，不再只占用少数固定点，也不再限制最多显示 12 个。较多果实时仍可能自然遮挡，但不会全部堆在原来的几个位置。
- 动物根据天空、树冠、树干或草地的生态位置在相应区域内分散出现。同一只动物刷新时位置保持稳定，不同遭遇可出现在该区域的不同位置。

### 商城与图鉴

- 商城余额旁增加“交易流水”按钮，以悬浮表格展示当前账号的时间、收支事项、金额变化和余额，支持每页 10 条翻页。果实回收流水使用对应果实的中文名称。
- 图鉴增加“树木装饰图鉴”，展示已发现与未发现的装饰、稀有度及拥有数量；按树上、地面、大型和具体子分类筛选，并支持分页。
- 装饰背包增加子分类筛选，开卡结果显示“装饰名称 · 子分类”，图鉴、背包和场景使用同一目录名称。

## 调整与修复

- 好友森林排行改为按**当日能量值**排序，不再按累计能量排序。
- 动物图鉴卡片移除名称下方的类别字样，左对齐展示季节、时段和天气；调整卡片高度，保证三项文字完整可见，并按每页两行展示。背包动物卡片只保留图片、名称和数量，缩小卡片尺寸；背包打开后不再定时刷新，切换分类时刷新。
- 移除本轮试制的 1500 件相似树木装饰。可抽取和可展示目录仅保留原有 **20 件**（树上 8、地面 8、大型 4），原有 ID、名称和图片保持不变。四张旧主题图片仅为历史数据兼容保留，不进入目录、抽取池或场景渲染。服务端和客户端目录同步使用版本 3 及子分类字段。
- 树木装饰目录在服务端增加 ID、名称、分类、子分类、稀有度和图片键校验；旧缓存缺少子分类时，客户端回退到原有摆放大类。

## 安装与兼容

- 提供 Windows x64 Direct 版 Native AOT 安装包 `SltBox_Setup_2026103002_x64.exe`，适用于 Windows 10 21H2（19044）及以上 x64 系统。安装包未签名，可用同名 `.sha256` 文件核对。
- 钉钉群文档云索引需要配套 PHP 接口和数据库表。账号须已登录 SltBox，且钉钉 DWS 授权须与绑定的钉钉账号一致。
- 更新程序优先使用 GitHub 安装包，失败时使用 `http://sltbox.2leaves.cn/releases/` 镜像，并按更新清单中的 SHA-256 校验。本次不发布 ARM64 或 Microsoft Store 安装包。
