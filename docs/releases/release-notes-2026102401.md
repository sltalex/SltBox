# SltBox 2026102401

## 种树与动物

- 满级树隐藏阶段进度条。树木保持原有大小并整体下移，给天空中的飞鸟留出空间；适合飞行的鸟会横穿画面，地面鸟和涉水鸟保留原有习性动作。
- 调整动物相对树木的显示尺寸和运动轨迹，并补全部分小动物的全身 SVG 形象。
- 增大动物与果实的点击范围。动物现在单击即可收藏，遇到后台刷新时会等待处理；采果点击会立即显示反馈，采果前只等待必要的种树进度同步。
- 背包动物卡片展示可遇见的季节、时段和天气；动物、果实数量使用与水族馆一致的角标样式。

## 图鉴、果实与账号

- 图鉴按当前页按需加载图片和列表，减少切换与刷新时的卡顿。
- 果实出售支持自定义数量。卡片左侧为图片，右侧上方是数量和“卖”，下方是“全卖”。
- 手动同步入口移到“设置 → 常规 → 账户登录”。

## 服务端与管理后台

- 增加动物图鉴管理，可调整名称、启用状态和遇见权重，并检查所有季节、时段和天气仍有可遇见动物。
- 增加果实、水族馆和动物图鉴的用户总体获得数量报表。
- 修复部分动物备份恢复数据与果实采摘请求的兼容问题。

## 安装包

- 本次提供 x64 Native AOT 安装包。安装包未签名，可用同名 `.sha256` 文件核对完整性。
- 桌面端功能依赖配套 API 更新。
