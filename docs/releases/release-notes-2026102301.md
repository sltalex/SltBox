# SltBox 2026102301

## 本次更新

- 果实显示改用独立透明 PNG 资源，修复旧图集裁剪串入相邻果实的问题。
- 树上果实、商城和果实图鉴统一使用独立资源目录；未发现果实使用透明模糊图。
- 保留现有 112 种果实目录、分类、概率和价格配置，额外图片仅作为本地资源保留。
- 果实资源导入增加 RGBA、文件配对、重复映射和安全路径校验。

- 本版本为 x64 Native AOT 完整安装包。
- 安装包未进行 Authenticode 签名，下载后可使用随附的 `.sha256` 文件校验完整性。
- 本次发布不包含 API/Web 端部署变更。
