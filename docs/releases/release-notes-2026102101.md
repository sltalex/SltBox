# SltBox 2026102101

## 本次更新

- 管理员管理从桌面端设置迁移到独立的 Web 管理后台，支持管理员登录、用户检索、启用或禁用账号、改名、撤销会话、删除账号，以及维护水族馆金币和果实回收价格。
- 管理后台增加分页、会话撤销和 CSRF 防护，并保留服务端管理员权限校验；桌面端不再显示管理员设置入口，普通账号也不会看到管理员菜单。
- 种树同步改为以服务端按操作增量累加为准；进入相关设置或恢复会话时先读取云端状态，避免同一账号在多台设备间互相覆盖总能量。
- 兼容旧版树服务端的状态读取入口；版本冲突处理后记录新的云端基线，避免同一批本地增量被重复上传。
- 水族馆商城和回收功能继续采用紧凑卡片布局，回收果实独立成卡片，管理员可以维护回收价格。
- 水族馆设置页面补充商城与回收卡片的展示契约，相关客户端测试同步更新。
- 待办的日期相关状态在跨过午夜后会自动刷新当天列表和数量，避免日期切换后仍显示旧结果；待办窗口会定期检查日期变化并在关闭时停止定时器。
- 保留近期的文件格子手工排序、水族馆、钉钉群文档、种树同步等功能更新。

## 注意事项

- 本版本为 x64 Native AOT 完整安装包。
- 安装包未进行 Authenticode 签名，下载后可使用随附的 `.sha256` 文件校验完整性。
- 管理后台使用当前服务器 HTTP 地址访问；HTTP 传输风险仍按现有部署限制处理。
