# SltBox 2026102001

## 本次更新

- 优化随记和待办的分类栏位置设置：支持顶部、左侧、右侧独立设置。
- 左侧、右侧分类栏复用顶部 Segmented 样式，保持相同的背景、选中态、悬停态、边框和间距；仅文字改为竖排。
- 中文按字竖排，连续数字保持横排，例如“第12阶段”中的“12”不会拆开，避免侧栏被拉得过长。
- 待办会议分类和随记分类在侧栏切换时与顶部选中状态保持同步。
- 修复侧栏切换后分类状态不同步、会议页面侧栏选中状态不一致的问题。
- 继续保留水族馆、钉钉群文档、种树云端同步和管理员功能等近期更新。

## 注意事项

- 本版本为 x64 Native AOT 完整安装包。
- 安装包未进行 Authenticode 签名，下载后可使用随附的 `.sha256` 文件校验完整性。
