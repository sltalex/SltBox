# SltBox 2026110701

本次更新相对于正式版 **2026110501**，新增 30 款花草植物装饰、到访摘果和可选的水族馆桌面背景，完善同步校准、2D 云层与动画、动物图鉴和快捷方式拖动行为。

## 新增：30 款花草植物装饰

- 新增薰衣草花丛、向日葵花田、郁金香花带、雏菊花簇、牡丹花丛、绣球花球、荷花盆栽、菖蒲水草、芦苇丛、蕨叶盆、龟背竹盆、仙人掌盆、多肉花盆、竹笋簇、小竹林、藤本花架、牵牛花架、玫瑰拱门、蔷薇花墙、茉莉花架、薄荷花盆、香草木箱、芦荟盆、茶树苗、蓝莓灌木、草莓垄、南瓜藤架、玉米花圃、麦穗花束和竹编花篮。
- 新装饰全部属于“地面 → 花草植物”，按普通、稀有度分配；每款有独立中文名称、独立轮廓和具体品类，不使用主题分类，也不重新加入已删除的主题装饰。
- 原有 20 款装饰保持 ID、名称、顶层分类、子分类、稀有度、asset key 及 SVG 资源不变，已有库存和场景布置继续有效。

## 目录、接口与资源同步

- 客户端和服务端目录统一为目录版本 3，共 50 项：树上 8、地面 38、大型 4；其中花草植物 32 项。
- 目录条目继续包含 `id`、`name`、`category`、`subcategory`、`rarity` 和 `asset_key`，图鉴、背包、抽卡结果、场景布置和到访场景共用同一份目录。
- 新增 30 款装饰分别生成 Source 与 Blur SVG，随客户端安装包离线提供；不依赖外部图片地址。
- 服务端已同步目录 JSON 和树木装饰目录、状态、操作接口。登录后刷新或切换账号会更新本地账号缓存，旧缓存缺少新增条目时不会破坏已有库存。
- 本次新增目录不需要数据库迁移：数据库继续保存账号库存、数量和场景，目录由服务端 JSON 提供。

## 新增：到访好友摘取果实

- 可在好友森林排行中到访其他用户，直接点击对方树上的果实发起摘取。自己不能到访自己。
- 按“树木主人 + 访客 + 果实品类 + 当天日期”限制次数：同一访客每天在同一用户处，每个果实品类最多摘取 1 个。
- 摘取前，该品类在对方树上的未采摘数量必须至少为 2；每次只转移 1 个，保留至少 1 个。例如对方有 3 个品类、各 3 个，同一访客当天最多摘取 3 个，每个品类 1 个。
- 服务端使用事务、唯一记录及操作标识处理并发与重复请求；确认成功后，扣减主人树上的对应果实，并增加访客背包中的果实。
- 点击后先进行本地数量检查，移除所点中的一个果实，提示“已加入队列”，再在后台依次发送请求；只有服务端确认后才提示成功。失败时恢复本地显示并提示原因，避免把排队误当作成功。
- 同一品类处理期间及成功后禁用本次窗口内的重复摘取；重新打开到访场景时，服务端仍校验每日次数。
- 修复摘取一个品类时把该品类所有图像一并移除的问题。果实按钮改为透明，保留点击区域，去掉明显的按钮底色与边框。
- 到访摘果使用配套接口和 `tree_visit_fruit_picks` 表，保留原有到访次数、用户信息和每日点赞功能。

## 调整：同步校准防止长时间等待

- “设置 → 功能格子 → 种树”的同步校准显示当前尝试次数和 20 秒倒计时。
- 单次超过 20 秒后取消当前请求，再重新尝试；首次尝试失败后最多重试 3 次，共最多 4 次尝试。
- 网络持续失败时停止当前校准，提示检查网络或点击“种树异常修复”，并恢复按钮可用状态。
- 校准期间切换账号会停止旧账号的操作与提示，避免上一账号的结果覆盖新账号界面。阶段能量门槛和日常能量计算保持原有规则。

## 修复：2D 树木天空与动画

- 将 2D 树木与 3D WebView 宿主拆分为同级视图，2D 模式下折叠 3D 宿主；3D 失败时同样恢复独立的 2D 绘制。
- 2D 树木动画改为轻微水平位移，避免旋转 SVG 素材时在顶部天空出现拉伸图像的合成路径；树冠和果实叠层增加位图缓存。此项针对已反馈的云后树木闪帧问题，实际显示仍取决于设备图形环境。
- 调整云层顺序，使其位于树体之上；天气尚未返回时也先初始化天空，恢复打开格子时缺少云的问题。
- 保留 2.5D 地图的镜头旋转、滚轮缩放、自适应高度、透明背景以及初始化失败自动回退 2D 的行为。

## 新增：可选的水族馆桌面背景

- 在水族馆设置中提供桌面背景开关，默认关闭；主动开启后，将当前账号水族馆场景呈现到桌面背景层。
- 按各显示器比例适配场景宽度，保持已有物件的归一化布置；随账号、场景和显示器变化更新。
- 增加缓慢背景漂移、水下薄雾、细小悬浮颗粒及景深透明度效果，沿用已有生物游动与水草动画。
- 关闭开关或退出应用时关闭背景窗口；不改变水族馆库存、交易或已保存的场景位置。

## 调整：图鉴、背包与文件格子

- 动物图鉴优先排列已经发现的动物；已发现卡片增加偏好天气、出现地点、活动方式和完整出没描述，缺少生态资料时显示待同步信息。
- 调整动物卡片宽度并允许文字换行，继续保留分页；主图鉴页签更清晰地标识当前选中项。
- 水果与动物背包分类按当前持有的品类计数，图鉴按已发现数量展示进度，两者各自使用对应的统计口径。
- 修复在文件格子内拖动 `.lnk`、`.url` 快捷方式到其他应用图标时被误当作“用此应用打开”的问题，使快捷方式拖动继续用于手动排列；普通文件拖到应用图标打开的行为保留。
- 补全到访摘果、同步倒计时与重试提示的多语言文本。

## 安装与兼容

- 提供 Windows x64 Direct Full Native AOT 安装包 `SltBox_Setup_2026110701_x64.exe`，适用于 Windows 10 21H2（19044）及以上 x64 系统。
- 安装包未签名，同时提供同名 `.sha256` 文件用于完整性核对；本次不发布 ARM64 或 Microsoft Store 包。
- 应用更新优先从 GitHub 下载，失败时使用 `http://sltbox.2leaves.cn/releases/` 镜像，并按 `update/stable.json` 中的 SHA-256 校验。
- 已有装饰库存不会自动增加新植物；新增植物会出现在装饰图鉴和抽卡目录，抽取后进入背包。旧客户端没有新增 SVG，需安装本版本才能显示新资源。
