# SltBox 2026111201

本次更新相对于正式版 **2026110801**，完成共享小镇第一版的 NPC Agent、动态通行和实时多人基础闭环，并修复了素材管理、地图状态和客户端实时桥接中的问题。本次发布提供 Windows x64 Direct Full Native AOT 安装包；Microsoft Store 和 ARM64 包不在本次发布范围内。

## 共享小镇：WebSocket 实时多人

- 共享小镇客户端新增 WebSocket 连接，首次连接获取完整快照，之后接收玩家、NPC 和世界状态的增量事件。
- 连接中断、鉴权过期或代理不支持 WebSocket 时自动回退到原有 HTTP 轮询；恢复连接后重新拉取快照并继续接收增量。
- 为会话增加旧事件过滤、重复实体更新保护和连接代次检查，避免旧响应把玩家或 NPC 拉回旧位置。
- 玩家移动、NPC 移动、任务状态和对话事件使用同一套实时状态桥接，不改变服务端的最终碰撞和权限校验。
- 当前实现已经通过服务端、客户端和 Worker 的实时协议测试；两个真实账号同时打开同一小镇的画面流畅度和断线重连仍需最后一轮人工验收。

## 共享小镇：NPC Agent 第一版

- 新增 5 名样例村民，包含姓名、头像/外观、人格特征、价值观、家庭背景、职业、短期目标、长期目标和 7 天日程，可在后台继续添加、编辑、停用和删除。
- 首版职业包括农夫、商人和工匠；村民可以执行行走、工作、休息和交谈，农田、集市和工坊会产生对应的确定性工作结果。
- 每名村民拥有当前位置、当前任务、运行状态、心情和最近对话；客户端显示姓名、状态动画和简短对话气泡。
- Worker 以 Linux/Docker 常驻服务运行，通过 PHP API 操作小镇，不直接写数据库；同一时间只有持有全局租约的 Worker 可以推进村民状态，租约失效后可被其他实例接管。
- 未配置模型、模型超时、模型不可用、额度用尽或返回非法行动时，Worker 自动回退到确定性日程，不会阻塞地图和村民显示。

## 动态导航与通行能力

- 共享小镇素材可配置 `plain` 普通地面、`blocked` 阻挡物、`stairs` 楼梯/高度转换、`water` 河道和 `bridge` 桥梁等导航语义。
- 导航数据记录高度、连接方向、交互点、受影响区块和所需能力；未配置语义的素材默认不可通行，避免把未知素材误判成道路。
- 首版支持 `ladder` 的 `climb_cliff` 能力和 `bridge_kit` 的 `cross_water`/`build_bridge` 能力。缺少道具时村民会绕路或进入等待状态，不会穿过阻挡物或河道。
- 服务端统一执行 `can_traverse`、`find_route`、能力检查、交互点预约和道具使用；模型只能返回意图和步骤，不能直接修改坐标或数据库。
- 地图素材变化会递增导航版本，旧路线在版本不一致时失效并重新规划；现有地图编辑、素材层级和玩家位置保存继续有效。

## 模型管理、日志和 Token 报表

- Web 管理后台新增模型配置、连接测试、启用/停用、模型名称、温度、超时和月度 Token 额度设置。
- API Key 只在服务端加密保存，WebView 不回显完整密钥；Worker 通过服务身份读取模型配置，并兼容没有后台模型配置时的服务端环境变量回退。
- 后台按人物和时间范围显示详细活动日志：模型调用、行动、说话内容、行走路径、心情变化、失败原因、输入/输出/总 Token、耗时、模型和供应商。
- 调用前使用原子 Token 预留，完成后按模型实际用量结算；超出月度 Token 额度时不会发起模型请求，而是记录原因并回退日程。
- 新增费用单价/币种、供应商修订历史和运行成本快照的数据结构与只读报表；线上真实价格配置后的长期费用归档仍需持续观察。

## 管理后台与客户端修复

- 共享小镇素材后台修复框选素材保存参数，改善分类、预览、地图尺寸和资源回读；增加导航配置和导航重建入口。
- 小镇地图支持更大的世界尺寸和完整的实时状态桥接；人物位置继续按账号保存，重新打开时从上次位置恢复。
- 修复 WebView 客户端实时连接初始化、鉴权令牌刷新和 NPC 图集/素材显示的边界问题。
- 保留前一版本的水族馆桌面背景、2.5D 种树地图、动物图鉴、账号同步和快捷方式修复。
