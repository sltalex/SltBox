# SltBox 2026102002

## 本次更新

- 文件格子新增文件图标自由拖动排序，支持将文件拖到目标位置进行手工排列。
- 图标视图和列表视图统一支持手工重排，并显示清晰的插入位置提示。
- 拖动文件图标后自动切换为“手工排序”，排序结果会保存到当前文件格子配置。
- 文件格子刷新、重新打开或重启 SltBox 后，已设置的文件顺序仍会保留。
- 补强普通文件图标区域的拖放事件路由，避免内部排序误进入文件导入流程。
- 保留文件夹投放、外部文件拖入、快捷方式打开等已有拖拽行为。

## 注意事项

- 本版本为 x64 Native AOT 完整安装包。
- 安装包未进行 Authenticode 签名，下载后可使用随附的 `.sha256` 文件校验完整性。
