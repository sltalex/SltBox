# SltBox 2026102302

## 种树与自然场景

- 缩小树木插画并保留卡片顶部空间，让太阳和天气效果与树冠各有展示区域；树干仍落在地面上。
- 为种树格子增加晴、阴、雾、雨、雪和雷暴等天气画面及对应的轻量动画。天气地点切换时会清除旧画面，避免沿用上一地点的状态。
- 昆虫、飞鸟、小动物各扩充至 60 种，共 180 种。出现种类由节气季节、当地时段和实时天气决定；每种都有适合其习性的短循环动作，并按树木比例控制显示大小。
- 登录后可遇见、双击收集动物。动物图鉴和背包按类别展示收集进度；云端保存遇见与收藏，账号备份及恢复也包含动物数据。
- 背包增加独立的“果实”分类，显示已收集的果实及数量。果实、水族馆和动物图鉴增加分类筛选及已获得数量。

## 同步、账号与更新

- 将种树手动同步和同步状态修复入口放到“设置 → 种树”。修复只清理本地同步协议状态文件，不删除种树进度；钉钉收藏等附加数据同步失败时，种树进度仍可独立完成同步。
- 水族馆改为已登录账号可用，并完善账号切换时的显示和数据隔离。
- 新增默认关闭的“自动更新”开关。启用后，新版安装包下载失败会重试；安装前保存设置并创建本地恢复快照，已校验的安装包交给静默安装助手。每个版本最多自动发起一次安装。

## 服务端与管理后台

- 野生动物接口和目录支持 180 种动物的条件筛选、遇见、收藏和恢复；动物收藏按账号保存。
- 果实目录使用独立透明 PNG 映射，并调整果实出现概率及价格档位。管理后台支持果实目录编辑，整理了后台操作处理逻辑。
- 水族馆接口以登录账号鉴权；钉钉群文档收藏接口兼容现有数据字段格式。

## 发行说明

- 本次提供 x64 Native AOT 完整安装包。安装包未做 Authenticode 签名，可使用同名 `.sha256` 文件核对完整性。
- 本版本的桌面功能依赖配套 API 更新。服务端部署状态以发布验证记录为准。
