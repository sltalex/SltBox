# SltBox 2026102702

本版整理任务格子的会议展示、钉钉群文档和种树设置，并新增树木到访。以下内容相对于 2026102701。

## 任务格子与会议

- 每日会议列表显示该次会议的参会人员姓名；钉钉未提供姓名时显示暂无人员信息。
- 修复会议页面停留一段时间后，其他任务列表内容叠加到会议区域的问题。切换到会议时隐藏任务列表及详情，返回任务时恢复对应面板。

## 钉钉群文档

- 群消息中的钉钉多维表链接与 Office 文档链接会进入现有的群文档格子，与在线文档一起按群整理。Office 文件通过钉钉消息中的文件资源链接识别；本功能保存和打开链接，不下载文档正文到本地。
- 老的群文档索引会重新扫描，以补入先前未识别的文件类型。同步仍依赖已授权的钉钉账号及群消息访问权限。
- 文档格子按筛选结果分页，跨群合计每页显示 **5 条文档**。底部提供上一页、页码和下一页；搜索或切换“全部 / 收藏”时回到第一页，内容变化后自动调整到有效页码。

## 种树、装饰与商城

- 种树设置采用更紧凑的宽度和左对齐布局。装饰背包在空间足够时每行显示四张卡片，缩小卡片内部边距而保持图片尺寸；较窄窗口会按可用宽度减少列数。
- “参与排行榜”开关与“同步校准”等按钮调整为同一行；排行榜中的阶段、增长、能量、果实、到访次数和操作按列排列，减少换行。阶段文字居中显示在彩色背景内。
- 商城的森林卡牌换为新的透明背景图片，并按卡片区域等比显示。
- 装饰场景在服务端保存时接受实际 JSON 请求解析产生的对象项，修复部分场景保存失败的情况。

## 树木到访与点赞

- 排行榜显示每棵树累计到访次数。点击其他用户的“到访”会打开只读悬浮窗，展示对方的名称、阶段、能量、树木场景、果实数量及点赞信息；右上角提供关闭按钮。
- 到访场景使用前端树木的主要图层与装饰布局；目前只供查看，不提供摘取果实或捕捉动物操作。
- 每位用户每天可给同一棵树点赞一次。点赞总数累计显示，同一天重复请求不会增加次数，次日可再次点赞。
- 自己的排行榜行不显示“到访”按钮；客户端和服务端都阻止自己到访自己的树。未参与排行榜的树不可到访。

## 设置与下载

- “后台设置 → 关于”的“检查更新”旁增加“版本下载”，点击后打开 [SltBox 下载网站](http://sltbox.2leaves.cn/)。窄窗口下按钮改为纵向排列，避免超出设置页宽度。

## 安装与说明

- 本次提供 Windows x64 Direct 版 Native AOT 安装包 `SltBox_Setup_2026102702_x64.exe`，适用于 Windows 10 21H2（19044）及以上 x64 系统。安装包未签名，可用同名 `.sha256` 文件核对。
- 应用更新先从 GitHub 下载；失败时使用 `http://sltbox.2leaves.cn/releases/` 镜像，并按更新清单中的 SHA-256 校验。此版不发布 ARM64 或 Microsoft Store 安装包。
- 树木到访需要配套 PHP 接口。服务器发布及公开下载的验证结果以本次发布记录为准；本地单元测试不能替代已登录账号的实际点击验证。
