7paws Windows 7 SP1 x64 兼容便携版

这是非官方旧系统兼容构建，不是微软或 Tauri 对 Windows 7 的官方支持。
Windows 7 已停止安全更新，内置的 WebView2 109 固定运行时也不会自动更新。

使用方法：
1. 将 ZIP 中的全部文件解压到同一个本地目录。
2. 保持 7paws.exe 与 WebView2Runtime 文件夹同级。
3. 双击 7paws.exe 运行。不要从 UNC 或网络路径运行固定版本运行时。

Windows 7 使用原生分层窗口呈现 3D 小猫，帧率限制为约 30fps。
设置窗口在该构建中使用不透明背景。
