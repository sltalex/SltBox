# 更新日志

本项目的所有重要改动都记录在这里，版本号与 git tag 一致。

## [0.4.2] - 2026-11-26

### 修复

- 打字时视线改为跟随实际按下的键位，而不是敲键的爪子：空格等居中键正视前方，不再在每打完一个词后向左看；换行、退格、符号键和左右手字母区也按真实键位偏转视线。

### 调整

- 渲染节奏按忙碌度调度：忙碌 60 FPS、空闲约 18 FPS、深睡约 12 FPS，高刷新率屏幕封顶 60 FPS，键鼠输入时立即打断低帧率定时器恢复满帧。
- 鼠标移动事件节流到 33 ms，并在 Windows 上丢弃 ≤1px 的抖动，减少高回报率鼠标的 IPC 与无效唤醒。
- 命中测试轮询按光标与窗口的距离自适应（近窗 25 ms、远窗 50 ms、隐藏 120 ms）；置顶守卫不再每个 tick 枚举窗口，只在前台切换、恢复过程中或每 900 ms 兜底执行，降低空闲 CPU 占用。

## [0.4.1] - 2026-11-25

### 新增

- 内置毛色预设由 7 种扩展到 13 种，新增黑猫、灰白猫、橘白猫、玳瑁猫、奶油猫和银渐层。
- 设置页毛色预览、MCP 内置毛色列表和 README 预览参数同步支持全部 13 种预设。

### 调整

- 优化暹罗猫配色，并改进双色与三色毛色色块预览。
- README 增加贡献者名单。

## [0.4.0] - 2026-11-25

### 新增

- 定时语音提醒：设置里新增「定时提醒」分区，提供开关、提醒内容文本框与间隔分钟数输入框（1–1440，默认 30）。开启后小猫按间隔到点用系统语音（Web Speech API，`zh-CN`）朗读提醒内容，提醒后自动重新计时循环；提醒内容留空则跳过朗读。
- 提醒计时运行在常驻的小猫主进程（`src/main.ts`），与设置窗口解耦：设置窗口关闭后提醒仍按时触发；改动开关、内容或间隔会立即按新设置重新计时（用配置指纹去重，避免改毛色等无关项时误重置倒计时）。
- 提醒设置随 `settings.json` 持久化，新增 `reminderEnabled` / `reminderText` / `reminderIntervalMinutes` 三个字段（前端 `AppSettings`、Rust `AppSettings` 与 `update_settings` 同步，间隔在 `normalize` 中钳制到 1–1440），重启后保留。
- 自定义猫新增第二个眼睛色槽（`eye2`）支持异色瞳：左右眼可分别配色，旧猫和旧毛色码自动回退到 `eye`；毛色码、MCP schema 与渲染器同步支持。

### 修复

- 修复选择照片时异常退出：原生文件选择器打开期间，全局鼠标钩子会把选择器内的点击判定为设置窗口外并销毁设置 WebView；在文件对话框仍打开时销毁 WebView2 可能导致 `0xc0000374` 堆损坏。现在选择器打开期间暂停自动关闭，Windows 还会检查设置窗口是否被原生对话框禁用。

### 说明

- 语音提醒使用系统本地语音合成（Web Speech API，`zh-CN`），不新增音频文件，也不新增网络请求。

## [0.3.0] - 2026-11-24

### 新增

- Windows 全屏游戏置顶守卫：持续检测 topmost 状态和前台窗口 Z 序，被无边框/全屏优化游戏盖住时自动恢复且不抢焦点；设置页提供可选的管理员身份重启。
- 新增「默认以管理员身份运行」开关，默认关闭；开启后下次启动按需请求 UAC，已提权时不会循环提示。
- 设置里新增「始终置顶」开关，默认开启；关闭后小猫会像普通窗口一样被其他窗口盖住，全屏置顶守卫同时停用。
- 内置「暹罗猫」毛色：奶油底配深棕重点色（脸罩、耳朵、四肢、尾巴）和蓝眼。
- 鼠标滚轮反应：滚动时桌面小鼠标跟着前后滚动并轻微俯仰，中间按键缝闪一下当前毛色的眼睛色；浏览器预览的 `?localinput` 也可体验。
- 闲置自由动作：短暂无操作后随机舔爪、舔毛、揣手或蜷缩，有输入时立即恢复，可在设置里关闭。
- 桌面快捷方式入口仅便携版显示，NSIS 安装版不再出现该按钮。
- Windows 设置页支持创建桌面快捷方式：指向当前 `7paws.exe`，保留工作目录、图标和说明，便携版无需安装即可使用。
- Windows 7 SP1 x64 非官方兼容便携版：独立 `win7` feature 与构建目录，VC-LTL 5.3.1 / YY-Thunks 1.2.3 兼容层，PE subsystem 6.01，内置 WebView2 109 固定运行时。
- Win7 原生分层窗口呈现：保留 three.js 3D 小猫，按帧合成 WebGL、按键气泡和睡眠 Z 字，支持动态命中、摸猫、拖拽、缩放、布局切换与位置持久化。

### 修复

- 毛色列表改为两列，修复设置页滚动条遮挡最右一列、长名字被裁切；超长名字显示省略号，悬停可见全名。
- 已提权时隐藏「以管理员身份重启」按钮和说明，避免无意义的重启和重复 UAC。
- 闲置动作保持在坐姿模型范围内，不再出现身体拉伸。
- 修复管理员重启切换时旧窗口销毁出现黑框、设置页连接中断；新进程等待单实例互斥量可用后再接管。
- 开发模式禁用管理员重启，避免出现控制台黑框和 `localhost:1420` 连接失败；该功能只在 Windows 发布包可用。
- 安装器和卸载器检测到可能以管理员权限运行的 7paws 时，显示明确退出提示，不再只报通用权限不足。
- Windows 增加会话级单实例保护：重复双击不再打开新进程，`--mcp` 子进程不受影响。
- Win7 离屏 WebView 改用 33ms 定时器驱动渲染，并直接关闭 Chromium 后台/遮挡节流，修复小猫不显示。
- Win7 帧缓冲与原生窗口按同一物理像素尺寸呈现，修复 125% DPI 下透明画面不合成。
- 主 WebView 保持屏幕外启动，主窗口和设置窗强制工具窗口样式，修复启动白框闪动与任务栏图标。
- 设置窗改为显示后按实际外框尺寸定位，修复 Win7 上隐藏窗口定位失效、左侧被裁切。

### 调整

- 精简管理员设置区：「默认以管理员身份运行」开关下不再显示说明，重启按钮说明改为「仅用于以管理员身份运行的游戏」。
- 呼噜声改为内置 MP3 录音，保留 WebAudio 循环、摸猫/睡眠独立开关和平滑淡入淡出。
- Win7 构建帧率限制为约 30fps，设置窗口使用不透明背景。
- Release 增加 `*-win7-x64-portable.zip`，校验 x64、subsystem 6.1、CRT/COM 导入和固定运行时完整性。

### 说明

- Windows 7 与 WebView2 109 均已停止安全维护；兼容包不代表官方或安全支持，仍需干净 Win7 SP1 x64 实机验证。

## [0.2.0] - 2026-11-23

### 新增

- 「我的猫」升级为命名多猫：毛色网格里可以新建任意多只猫，支持改名、4 个色槽（主色/花色/第三色/眼睛）、四种花纹（纯色/双色/虎斑/三花）、照片取色（本地聚类，不上传照片）、毛色码生成与导入，以及两步确认的删除；数据单独保存在 `cats.json`。
- 头部与身体斑纹（spots）：每只猫最多 24 处椭圆标记，可调位置、大小、旋转、颜色和透明度，用来表达额头纹、眼罩、白胸口、背部色块等个体特征。
- 内置 stdio MCP 服务（`7paws.exe --mcp`）：不依赖 Node/Python，AI 客户端可以读取 schema、按照片创建或修改「我的猫」，运行中的小猫约 1 秒内热更新。提供 `get_cat_schema`、`list_cats`、`upsert_cat`、`switch_cat`、`delete_cat` 五个工具；设置里可以一键复制 15 个客户端（Qoder 优先）的配置，也可以随时关闭 AI 接入。
- 透明度滑杆：10%–100% 调节整只小猫（含键盘与特效）的透明度。
- 检查更新：设置窗口右上角手动对比 GitHub 最新版本，有新版时引导到发布页；设置底部显示当前版本。
- 设置窗口标题栏增加 GitHub 仓库入口。

### 修复

- 删除自定义猫改为设置内两步确认（首次点击进入待确认状态，3 秒内再次点击生效），不再弹出带页面地址的原生确认框。
- 设置窗口关闭时直接销毁 WebView，不再常驻后台占用内存。

### 调整

- 渲染优化：闲置时半速、睡眠时约 15fps；高分屏 DPR 上限从 2 降到 1.5，降低显存与 GPU 占用。
- MCP 配置按客户端生成对应格式（`mcpServers` / VS Code 的 `servers` / Codex 的 TOML / DeepSeek Harness 的 YAML / OpenCode 的 `mcp` 数组）。
- 升级安装时，安装器会检测占用（包括 AI 客户端拉起的 `--mcp` 进程）并提示关闭后继续；以管理员身份运行的客户端需要先手动退出。
- README 增加操作演示、设置界面截图和 MCP 接入指南（含对 AI 的使用示例）。

### 说明

- 「检查更新」是应用唯一的联网行为，只在用户点击时读取版本号，不发送任何本地数据。
- 斑纹目前只覆盖头部和身体，四肢与尾巴暂不支持；坐标与模板见 MCP 的 schema 指南。

## [0.1.4] - 2026-11-23

### 新增

- 设置里可以关闭托盘图标（macOS 为菜单栏图标）；关闭后仍可右键小猫打开设置重新开启。
- 设置里可以打开开机自启（Windows 注册表 / macOS LaunchAgent）。
- Windows 增加便携版 zip（x64 / ARM64），解压后双击运行，无需安装；需要系统已安装 WebView2 Runtime。

### 修复

- Windows 安装器左下角显示产品名和版本，不再出现 `Nullsoft Install System`；安装器跟随系统语言，卸载器使用安装时的语言（老安装按系统语言兜底）。
- macOS 包改为 ad-hoc 重新签名（绑定 Info.plist、使用 `com.qoder.7paws`），修复 macOS 15+（含 26/27）上权限已授权但仍提示、键盘无响应的问题。
- macOS 26/27 的权限提示条注明「设备控制与数据访问」这一新名称。

### 说明

- macOS 仍使用 ad-hoc 签名，升级后如提示仍在，需要把两个权限开关重新开关一次；正式分发需要 Developer ID 签名与公证。
