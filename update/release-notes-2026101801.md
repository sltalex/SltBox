# SltBox 2026101801

本次提供 x64 Direct Native AOT 完整安装包，包含运行所需组件。

- 水族馆扩充到 158 种物品：50 种鱼、50 种水草、50 种假山与装饰，以及虾、蟹、贝类；更新对应的 SVG 素材。
- 水族馆商城改为顶部分类目录；背包按类别展示持有和已放入数量。独立背包可跳转到水族馆设置，布置仍在水族馆设置中手动保存。
- 水草和假山布置新增前景、中景、后景图层。旧布置默认按中景显示，保存后同步到桌面水族馆。
- 管理员、水族馆设置和独立背包仅对已验证的管理员账号显示；未登录时不显示这些入口。
- 新增管理员账号管理功能；更新检查可提示下载并记住自动更新偏好。
- 钉钉群文档收藏信息纳入本地和云账户 JSON 备份，恢复时保留收藏标记。
- 调整种树设置与排行榜布局，并加入四驱车格子。
- 安装包文件名、产品名称统一使用 SltBox；内部 `DeskBox.exe` 和数据目录保持不变，以兼容已有安装。

云账户 API 当前仍使用 HTTP，传输中的账号令牌及相关数据可能被截获；请避免在不可信网络中进行敏感操作。

安装包及 SHA-256 校验文件将同时提供于 GitHub Release 与下载镜像。
