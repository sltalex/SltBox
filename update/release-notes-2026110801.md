# SltBox 2026110801

发布日期：2026-11-08。以下为相对于 2026110701 的更新内容。

## 果实按品类累加与整类采摘

- 保留累计 144,000 能量进入第五阶段的成熟门槛。成熟后，默认每新增 3,000 能量触发一次结果；每次按现有品类概率选择一种果实，再等概率生成 1～5 个，同品类在树上累加。
- 本人点击某品类的果实，收取服务器处理该次采摘时该品类的全部果实，直接进入背包；采摘时不再额外随机增加数量。其他品类不受影响。
- 2D、3D 和到访场景均按品类展示果实，每个品类使用一个图标，数量变化后更新相应状态，避免同品类大量果实重复堆叠。
- 本人种树前端隐藏数量标签；到访界面保留靠近果实的小号数量标签，并移除数量前的乘号，例如原来的“×3”改为“3”。继续使用透明点击区域。

## 到访摘果与同步一致性

- 保留到访规则：对方该品类至少有 2 个果实时才能摘取，每次获得 1 个；同一访客每天对同一用户的每个品类可摘取一次，至少为对方留下 1 个。
- 到访摘取后按服务器返回的剩余数量校准，剩余数量大于零时保留对应图标；失败时恢复本地展示数量。
- 本人采摘、访客摘取和产果流程继续由服务器事务处理，并通过操作编号识别重复请求，避免重试重复领取。
- 同步期间继续保留新产生的能量；离线时记录能量，恢复同步后由服务器计算实际产量，不在本地随机发放，也不把服务器确认的果实再次当作本地增量上传。
- 保留已有待采摘记录与背包数量，兼容旧版请求和缓存，避免旧版上传的估算数量覆盖服务器实际记录。

## 网页后台产果设置

- 在网页管理后台“果树 → 产果设置”增加三个可保存参数：每次结果所需能量、每次最少果实数、每次最多果实数。
- 默认值仍为 3,000、1、5；修改后用于后续产果，全体用户使用同一组配置，已有果实不重新随机或补发。
- 增加参数范围校验、管理员权限校验和审计记录；客户端读取并保存服务器返回的能量阈值，保持显示和同步计算一致。
- 本次相关 PHP 接口和新增配置表迁移已部署到线上服务器，并验证线上配置读取。

## 安装与兼容

- 提供 Windows x64 Direct Full Native AOT 安装包，沿用上一正式版的运行库随包方案，适用于 Windows 10 21H2（19044）及以上 x64 系统。
- 同时提供安装包 SHA-256 校验文件；应用更新继续优先从 GitHub 下载，失败后使用网站镜像，并校验文件完整性。
- 本次不发布 ARM64 或 Microsoft Store 安装包。
