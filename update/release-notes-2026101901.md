# SltBox 2026101901

发布日期：2026-10-19。本次更新集中扩充水族馆内容、改善商城与背包浏览，新增日历格子，并完善钉钉群文档收藏和后台更新检查。

## 水族馆：更多生物与景观

- 商城目录升级至 v7，共 341 种商品：150 种鱼、50 种水草、50 种假山与装饰、20 种珊瑚、20 种海藻、20 种螺类、虾蟹贝类各 10 种，以及 1 种水族卡包。
- 鱼类覆盖大型鱼、小型群游鱼等更多品种，按淡水鱼、热带淡水观赏鱼、海水鱼进一步分组，方便查找和搭配。
- 新增珊瑚、海藻和螺类的展示与布置支持，可购买、放入、收回、调整大小和前后层次；海藻具有轻摆效果。
- 素材随安装包提供，包含 340 对 SVG 原稿与透明 PNG。鱼、水草和假山采用写实风格插画，珊瑚、海藻、螺及部分小生物采用卡通插画；展示无需在线加载图片。
- 新增水族卡包：购买后可从背包开启，展示开包动画与随机物品奖励。重复请求使用同一操作标识，避免网络重试造成重复扣费或发放。

## 水族馆：商城、背包与游动体验

- 商城沿用多列商品卡片，分类改为顶部一级目录与二级目录，空间不足时自动换行，避免下拉选择和整行单个商品造成的冗长列表。
- 背包按物品类别浏览，鱼类支持进一步筛选；物品卡片更紧凑，便于查看持有数量、放入状态并进行收回操作。
- 水族馆布置继续通过“保存布置”统一保存并同步到桌面，独立背包中的水族馆入口可跳转到对应设置。
- 生物游动引入 10 个纵深层级：越靠后的位置越高、体型越小，越靠前的位置越低、体型越大，形成前后交错的空间感。
- 鱼、虾、蟹游出可见区域后才随机切换下一轮的层级，避免在视野内突然改变大小和遮挡顺序；游动效果不改写用户保存的布置。

## 新增日历格子与待办联动

- 新增按月浏览的日历格子，汇总各待办格子中尚未完成、已设置截止日期的任务；已完成、已删除和无截止日期的任务不会显示为日期任务。
- 支持显示任务标记、调整标记颜色，点击日期查看任务，并打开对应的待办格子。
- 可开启中国节日标记及下一节日倒计时，支持固定日期和农历节日；节日标记不等同于每年官方调休或放假安排。
- 待办新增默认截止时间及“本周”默认截止星期设置，减少重复填写。
- 修正农历闰月年份的节日换算；日历隐藏后重新显示会恢复定时刷新，关闭任务标记后节日倒计时仍会更新。
- 本版移除旧四驱车格子及入口。升级时会清理其桌面布局记录；新日历可在功能格子设置中启用。

## 钉钉群文档与日历

- 收藏改为按群会话身份区分。同一文档链接出现在多个群时，各群的收藏状态独立，避免错误关联。
- 兼容旧收藏数据，逐步迁移以群名保存的标识，保留收藏文档的标题、链接、群名等信息。
- 收藏元数据可独立保存与恢复，配合本地备份和云账户备份，减少对当前同步缓存的依赖。
- 收藏按当前 DWS 用户隔离；切换用户或授权失效时清理当前界面的旧用户收藏，避免混淆。
- 钉钉日历过滤已取消、已删除的会议，减少无效日程显示。

## 设置与更新

- 管理员用户详情调整为页面内联卡片，减少弹窗切换；管理员专属入口仍受账号权限控制。
- 自动更新在启动后检查，并每小时继续检查；应用退出时取消后台检查任务。
- 修复水族馆接口重复加载模块的问题，恢复目录、状态与操作接口的正常执行。
- 同步补充全部现有语言资源、设置搜索项及相关兼容性测试。

## 安装与兼容说明

- 本次提供 Windows x64 安装包，产品及文件名使用 SltBox，内部程序名、数据路径和既有安装身份保持兼容。
- 水族馆 v7 需要配套服务器 API；本次目录扩容无需新增数据库结构迁移。
- 云账户 API 继续使用当前 HTTP 配置；钉钉关联仍通过 DWS 完成本地授权。
- 安装包与 SHA-256 校验文件通过主 GitHub Release、旧仓库兼容发布页和下载镜像提供。
